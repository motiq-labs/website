AI-BOOST / Project in development

Language-based instructions for agricultural robots.

As part of the AI-BOOST competition, we are developing an approach that turns everyday instructions into a work plan for an agricultural robot. Our proposal was selected for the ADVANCE phase. Prototype development and validation are ongoing.

How it works

  1. Describe the task

    The user specifies what the robot should do and where.

  2. Build the plan

    The system creates a plan using actions the robot supports.

  3. Review and run

    The plan must be checked before execution. The system needs to identify requests it cannot carry out.

Prototype in development

We are developing planning and action validation. Testing on the target robot is still ahead.
